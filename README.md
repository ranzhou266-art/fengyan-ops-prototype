# 驭眼科技 · 风电运维管理平台 交互原型

线上地址：https://ranzhou266-art.github.io/fengyan-ops-prototype/

## 访问方式
打开上述地址 → 输入访问密码 → **直接进入「项目列表」页面** → 用页面左侧菜单切换到其它页面。
无中间导航页，落地即是原型本身。左侧菜单 13 个入口覆盖全部页面，一次输入密码后 30 天内全程免密。

## 包含页面（14 个）
| 模块 | 页面 |
|---|---|
| 产值管理 | 年度产值计划、项目月度产值管理 |
| 合同与项点 | 销售合同与项点、外包合同与项点 |
| 运维项目管理 | 项目列表（默认落地页）、项目概览、日报审核与管理、产品编号管理、产品编号状态管理、项目派单 |
| 执行与交付 | 完工报告管理、结算单管理 |
| 收付款管理 | 开票收款、外包付款 |

## 技术说明
- 纯静态站点，零后端、零外部资源（字体/图标均内联或系统自带）
- 14 个页面使用 Staticrypt 做 AES 静态加密，密码校验在浏览器端完成；根路径 index.html 仅为跳转页（不含业务内容）
- 页面源码公开但已加密，不知道密码无法查看内容

## 如何修改访问密码
1. 安装工具：`npm i -g staticrypt`
2. 对未加密源目录 `site/` 重新加密：`staticrypt site -r -d encrypted -p "新密码" --remember 30 -t _pw_template.html`
3. 用脚本把产物中 `<input id="staticrypt-remember" ... />` 加上 `checked`（否则每翻一页都要重输密码）
4. 再把明文跳转页覆盖回去：`cp site/index.html encrypted/site/index.html`
5. 把 `encrypted/site/` 下文件推送到本仓库 main 分支根目录，Pages 会自动重新部署

## 演示建议路线
合同与项点 → 运维项目管理 → 执行与交付 → 收付款管理，
可完整走通「合同 → 项点 → 项目 → 产品编号 → 完工报告 → 结算 → 收付款」全链路。
